# مشروع لوحة تحكم باستخدام CSS Grid

يحتوي المشروع على:

- index.html: الصفحة الرئيسية والإحصائيات.
- users.html: جدول المستخدمين.
- settings.html: نموذج إعدادات الحساب.
- style.css: تنسيقات الصفحات والـ Grid والـ Hover والـ Active Link.

## التشغيل

افتح ملف index.html في المتصفح، أو شغّل المشروع باستخدام إضافة Live Server في Visual Studio Code.
